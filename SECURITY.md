# Security policy

## Supported versions
Only the latest release of redis-dict on [PyPI](https://pypi.org/project/redis-dict/) receives security fixes.

## Reporting a vulnerability
Please don't report security issues in a public issue or pull request.

Report them privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**.
Include a description of the issue, the affected version, and the steps to reproduce it.

You'll get a response as soon as possible. Once a fix is released, the report is published as a security advisory, and you're credited unless you prefer otherwise.
